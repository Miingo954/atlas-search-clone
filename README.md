# Atlas Search Clone

A responsive search interface powered by Google Custom Search data.

## Features

- Live search results
- Google Custom Search API
- Responsive results layout
- Query-based search flow
- Loading and error states

## Built With

- React
- Vite
- JavaScript
- Google Custom Search API

## Requirements

- Node.js 20 or newer
- npm

## Installation

```bash
git clone https://github.com/Miingo954/atlas-search-clone.git
cd atlas-search-clone
npm install
```

## Run Locally

```bash
npm run dev
```

Open the local URL shown in your terminal.

## Available Scripts

```bash
npm run dev
npm run build
```
